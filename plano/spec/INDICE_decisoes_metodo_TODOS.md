## Como aplicar

1. **No Projeto:** substituir os arquivos pelos de nome novo. O conteúdo é igual, então os SHA continuam os da tabela.
2. **No repositório (`spec/`):**
   - **já commitados com o nome antigo** (por exemplo, o complemento e a D5, commitados pelo A1): **não renomear**, porque os logs citam o caminho antigo; basta commitar este índice;
   - **ainda não commitados:** commitar com o nome novo.
3. **Nos logs:** citar o nome que está no `spec/` daquele repositório, sempre com o SHA. O SHA identifica o documento, qualquer que seja o nome.
4. **Documentos novos:** já saem com o escopo no nome.
